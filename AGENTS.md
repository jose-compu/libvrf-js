# Git branches

Do not name a branch `cursor`, and do not put `cursor` in a branch name.
Name the branch after the change.

# Authorship

Do not attribute commits, pull requests, tags, releases, issues, or files to Cursor, Claude, Grok, ChatGPT, Copilot, Codex, or any other LLM or AI tool.

Do not add `Co-authored-by`, `Made with`, `Generated by`, or similar credits for those tools.

Commits and pull requests are authored only by the human maintainer.
